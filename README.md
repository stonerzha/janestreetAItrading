# janestreetAItrading

系统性梳理与总结基于简氏街（Jane Street）公开讨论所构建的**人工智能交易研究工作流**——特别参考与 Eric Mannes 的访谈《Wrestling the World Into Rows》及 Jane Street 官方发布资料。

## 核心思想

1. **明确区分 AI 在交易研究中的不同功能角色**，不把"抽取"、"编码"、"预测"混为一谈；
2. **严格维护点时间（Point-in-Time）数据完整性**，历史回测仅使用决策时刻确已可用的数据；
3. **产物驱动（Artifact-driven）的防错机制**，用可审计的中间产物防止后见之明（Hindsight）与数据泄漏。

## 核心要点

### 1. AI 的三大独立角色

| 角色 | 职责 |
| ---- | ---- |
| 信息抽取 | LLM 将非结构化文本转化为结构化事实 |
| 工具构建 | AI 辅助编写可复现的数据转化代码 |
| 预测评估 | 预测模型在严格边界内研究特征与未来的关系 |

三个角色相互独立：抽取不管预测，代码必须可复现，预测只在划定的数据边界内进行。

### 2. 三时钟原则（Three Clocks）

- `event_at` —— 事件发生时间
- `published_at` —— 发布时间
- `received_at` —— 接收时间

三者缺一不可：只有同时满足"事件已发生、已发布、已接收"，数据才能进入回测。

### 3. 六大核心产物架构

| 产物 | 作用 |
| ---- | ---- |
| 任务书（Mandate） | 定义研究任务的目标与边界 |
| 清单（Manifest） | 记录数据来源与版本 |
| 抽取表（Extraction） | 结构化抽取结果 |
| 特征表（Features） | 可复现的特征计算 |
| 评估报告（Evaluation） | 预测评估结果 |
| 日志（Journal） | 全过程审计日志 |

六大产物构成完整的可审计研究闭环：每一步输入输出都有据可查。

### 4. 模型前瞻泄漏与记忆消除

大语言模型的训练数据可能包含未来事件的结果（如 Enron 案）——模型"记得"答案，不等于它能预测。

应对方法：

- 将**数据时间边界**与**模型知识边界**解耦；
- 通过**向前观察（Forward Observation）**验证真实预测力，而非记忆复述。

### 5. 端到端实证演示

以英伟达（NVIDIA）FY2026 Q1 与 Q2 财报数据为例，展示从原始材料到研究结论的全过程：

原始 PDF/HTML 抽取 → 确定性代码计算 → 生成可审计研究工单

- 营收 QoQ 增长 **6.0846%**
- GAAP 毛利率增加 **11.9 个百分点**

## 仓库结构

- `docs/` —— 研究笔记（按主题整理）
- `research/` —— 原始资料收集（访谈、文章、技术分享）
- `src/` —— 代码实验（抽取脚本、特征计算、评估）
